# クイックセッションコーディネーター テンプレート

クイックタスクモード（モード B）で使用するセッション固有のコーディネーターファイル。
セッションごとに一意のファイル名で作成し、複数のクイックセッションが並行しても衝突しない。

ファイル名: `.parallel-dev/quick-session-{YYYYMMDDHHmmss}.md`

例:
- `.parallel-dev/quick-session-20250105143022.md`
- `.parallel-dev/quick-session-20250105150530.md`

---

## ファイル名生成

```bash
# タイムスタンプでユニークなファイル名を生成
SESSION_FILE=".parallel-dev/quick-session-$(date +%Y%m%d%H%M%S).md"
echo "セッションファイル: $SESSION_FILE"
```

---

## テンプレート

```markdown
# クイックセッション: {YYYYMMDDHHmmss}

## セッション情報

| 項目 | 値 |
|------|-----|
| 開始日時 | {YYYY-MM-DD HH:mm} |
| ベースブランチ | main |
| ステータス | 進行中 / 完了 |

---

## タスク一覧

| タスク名 | ブランチ | 依頼内容 | ステータス |
|----------|----------|----------|------------|
| {task-1} | fix/{task-1} | {依頼内容} | 作業中 / マージ済 |
| {task-2} | feature/{task-2} | {依頼内容} | 作業中 / マージ済 |

---

## 起動済み作業用 claude

| タスク名 | ウィンドウ名 | 起動コマンド | ステータス |
|----------|-------------|--------------|------------|
| {task-1} | {task-1} | `tmux new-window -n "{task-1}" "cd worktree/{task-1} && ..."` | 起動済 / 終了済 |

---

## 完了・マージ履歴

### {task-1}（{HH:mm} マージ完了）

- 変更内容: {変更ファイル一覧}
- テスト結果: パス
- コミット: {commit-hash}

---

## セッション終了チェックリスト

- [ ] すべてのタスクがマージ済み
- [ ] すべての作業用 claude を終了（`tmux send-keys -t "{task-name}" C-c C-c`）
- [ ] worktree をクリーンアップ
- [ ] ブランチを削除
```

---

## 使用手順

### 1. セッション開始時

```bash
# 1-1. セッションファイルを作成
SESSION_ID=$(date +%Y%m%d%H%M%S)
SESSION_FILE=".parallel-dev/quick-session-${SESSION_ID}.md"

mkdir -p .parallel-dev

cat > "$SESSION_FILE" << EOF
# クイックセッション: ${SESSION_ID}

## セッション情報

| 項目 | 値 |
|------|-----|
| 開始日時 | $(date '+%Y-%m-%d %H:%M') |
| ベースブランチ | main |
| ステータス | 進行中 |

---

## タスク一覧

| タスク名 | ブランチ | 依頼内容 | ステータス |
|----------|----------|----------|------------|

---

## 起動済み作業用 claude

| タスク名 | ウィンドウ名 | 起動コマンド | ステータス |
|----------|-------------|--------------|------------|

---

## 完了・マージ履歴

---

## セッション終了チェックリスト

- [ ] すべてのタスクがマージ済み
- [ ] すべての作業用 claude を終了
- [ ] worktree をクリーンアップ
- [ ] ブランチを削除
EOF

echo "セッションファイルを作成しました: $SESSION_FILE"
```

### 2. タスク追加時

セッションファイルの「タスク一覧」と「起動済み作業用 claude」を更新する。

### 3. タスク完了時

「完了・マージ履歴」にマージ結果を追記し、「タスク一覧」のステータスを「マージ済」に更新。

### 4. セッション終了時

チェックリストを完了し、「ステータス」を「完了」に更新。

---

## モード A（merge-coordinator.md）との違い

| 観点 | merge-coordinator.md（A） | quick-session-{timestamp}.md（B） |
|------|--------------------------|-----------------------------------|
| ファイル名 | 固定 | タイムスタンプで一意 |
| 作成タイミング | 計画書作成時に1回 | セッション開始時に毎回 |
| 複数並行 | 1つのみ | 複数セッション可能 |
| 依存関係管理 | 詳細に記載 | 基本的に独立タスク |
| マージ先 | 統合ブランチ | main 直接 |
